## Detailed description

Make informed decisions in WarEra with tactical information alongside the game.

Warera Tactical adds battle estimates, market comparisons, company calculations and opportunity radars to supported WarEra pages. Choose each feature independently in Settings; saved changes apply to your open game tabs.

• Battle insights: average damage, full-burst damage and cost estimates, expected box values, and available bounty or contract information.
• Market tools: price benchmarks, bargain highlights, equipment value comparisons and suggested order prices you can copy.
• Economy tools: company production advice and net salary calculations.
• Player and group insights: available player stats, pill timers, and country or military-unit build summaries.
• Opportunity radars: configurable bounty, contract-auction and loot-target views, with bounty notifications.
• English and Spanish settings and overlays.

API-backed features require a WarEra API token; some also need your player ID. Credentials and preferences are stored in your Chrome profile. API reads use WarEra's official services or the Community Gateway. Gateway requests send your API token and query to warerastats.io; limited automatic recovery from official rate limits can also use that gateway.

The extension is read-only. It does not fight, trade, submit orders or automate game actions. Suggested order prices are copied for you to paste yourself. Estimates depend on available data, prices and game rules; unavailable values are shown as such.

Warera Tactical is an independent companion and is not affiliated with or endorsed by WarEra. A WarEra account is required to use the game.
